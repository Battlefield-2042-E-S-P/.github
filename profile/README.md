## 🚀 Why Choose Battlefield 2042 ESP?

With 128 players and vehicles, clutter is the main enemy. The overlay keeps infantry information readable at range and adds vehicle context that plain player ESP leaves out. Filters let you cut everything beyond the fight you are actually in.

Each element toggles independently, so a vehicle-heavy layout and an infantry layout can coexist as profiles.

## 🧩 Quick Start

1. Launch **Battlefield 2042** and open the ESP panel.
2. Enable boxes, skeletons, health, and class info.
3. Set team colors and range filters.
4. Turn on vehicle indicators.
5. Save the layout as a profile.
